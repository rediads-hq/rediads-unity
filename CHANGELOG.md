# Changelog

## 0.1.0-beta1

First public beta.

- `com.rediads.ads`: Rediads banners, interstitials and rewarded ads (iOS SDK 0.1.3, Android SDK
  0.1.0-beta1).
- `com.rediads.ads.admob`: Rediads bids in AdMob mediation.
- `com.rediads.ads.gam`: Rediads in Google Ad Manager, bidding-only and SDK-rendered.
- Install from the Package Manager (Git URL) or as .unitypackage files.
